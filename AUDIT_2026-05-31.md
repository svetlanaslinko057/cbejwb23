## 5. Что НЕ развёрнуто в этом pod

| Компонент                | Причина                                                                 |
|--------------------------|-------------------------------------------------------------------------|
| `/web` (React CRA, 98 страниц) | Pod поддерживает только backend + Expo; нужен отдельный сервис    |
| `sentence-transformers` (1 lazy import в `server.py:17352`) | Опущен ради экономии диска; функция использует ленивый импорт — без неё работает всё, кроме конкретного embedding-вызова |
| `scikit-learn`, `scipy`, `networkx`, `sympy` | Транзитивные зависимости sentence-transformers — пропущены |
| Production build mobile (APK/IPA)| Делается через кнопку «Publish» в правом верхнем углу платформы Emergent |

## 6. Известные предупреждения (не блокеры)

1. `Duplicate Operation ID audit_log` — функция `audit_log` в `admin_users_layer.py`
   имеет дубль OpenAPI operation_id. На рантайм не влияет.
2. `LEGACY ENDPOINT CALLED: /api/client/workspace` — устаревший URL,
   мигрировать на `/api/client/project/{id}/workspace`.
3. `[expo-notifications] Listening to push token changes is not yet fully supported on web` —
   только web таргет; на iOS/Android работает штатно.
4. Ngrok иногда переподключает тунель при холодном старте Expo (transient).
